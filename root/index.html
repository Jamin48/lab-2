Unit Outline

COS10026 - Web Technology Project

Aims

This project-based unit focuses on developing your skills to build web applications using web technologies. You'll work individually and in teams to tackle real-world challenges. The unit also covers essential aspects of security, ethics, accessibility, and professional communication.

Unit Learning Outcomes

  1. ULO1: Identify web technologies’ core components and functions.
  2. ULO2: Implement a project plan using project management strategies.
  3. ULO3: Apply team frameworks to work effectively.
  4. ULO4: Use database query techniques (CRUD).
  5. ULO5: Develop functional web apps using ethical and secure practices.
  6. ULO6: Explain and implement security principles.
  7. ULO7: Assess ethical and accessibility practices in web development.

Contents

  • Front-End and Back-End Development
  • Version Control & GitHub
  • Project Management & Teamwork
  • Web Security, Ethics, and Accessibility
  • Databases and CRUD
  • Communication & Presentation
